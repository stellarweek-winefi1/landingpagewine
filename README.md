# Vinifica Landing Page

Landing page for Vinifica - a wine traceability platform.

## Getting Started

First, install the dependencies:

```bash
npm install
```

Then, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Project Structure

- `app/` - Next.js app directory with pages and layouts
- `components/` - React components for the landing page
- `public/assets/` - Image assets
- `lib/` - Utility functions

## Features

- Hero section with call-to-action buttons
- Why invest section with benefits
- How it works section with features
- Call-to-action section
- Responsive navigation
- Smooth animations using Framer Motion
